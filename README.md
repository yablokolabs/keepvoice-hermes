# KeepVoice for Hermes

**Keep the voice. Review the cut.** Start a clip cleanup job in Hermes, see what needs a human check, and retrieve the export for the approved revision.

This is the build kit for a new native Hermes plugin. It reuses the existing KeepVoice media service. The plugin, live demo, catalog PR and contest submission are pending.

1. Create or open a working checkout named `keepvoice-hermes`. Copy this kit into it.
2. Paste [BUILD_PROMPT.md](BUILD_PROMPT.md) into your coding agent. Keep Hermes available to run the actual plugin.
3. Build and test using [PROJECT_BUILD.md](PROJECT_BUILD.md) and [docs/API_CONTRACT.md](docs/API_CONTRACT.md).
4. Record the live proof and submit using [docs/DEMO_AND_SUBMISSION.md](docs/DEMO_AND_SUBMISSION.md).

Deadline: **November 11, 2026, 5 p.m. EST / November 12, 2026, 3:30 a.m. IST**. Submit the catalog PR and X post URLs through the form. A merge is not required by the deadline.
